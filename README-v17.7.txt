Моя Бауманка v17.7 — личная версия
Установка: распаковать содержимое ZIP В КОРЕНЬ репозитория moyabaumanka.
Не публикуйте резервные копии с личными оценками в публичном репозитории.
Перед заменой файлов: в профиле приложения экспортируйте резервную копию.
Автоматический локальный снимок: ключ baumanka_autobackup_v177 (не заменяет ручной экспорт).
Для тестов: node tests/smoke.test.cjs
Ограничение: тесты проверяют структуру и календарные инварианты, но не заменяют ручное тестирование iPhone и браузера.
Важное: при публикации в GitHub Pages данные localStorage сохраняются только для того же домена/браузера; облачной синхронизации в этой версии нет.
