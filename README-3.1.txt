SMART STUDY 3.1 — статическая сборка, без npm.
Загрузить содержимое в основной репозиторий после экспорта данных.
Виджеты: карточка дня или профиль; порядок меняется стрелками.
Долгое нажатие: главная — виджеты, расписание — новая пара, задания — новое задание, учёба — билеты, профиль — настройки виджетов.
Уведомления работают только при открытом активном приложении; фоновые push не реализованы.
Фото сжимаются и хранятся локально вместе с заданиями; объём ограничен браузером.
Сессия: пять предметов из seed, контрольные фильтруются отдельно, старые записи не удаляются.
Проверки: node --check app.js, node tests/smoke.test.cjs, node tests/nav.test.cjs. Реальный браузер не проверен.
