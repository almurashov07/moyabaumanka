Моя Бауманка 2.4 NATIVE MATCH
Главная полностью перестроена по утверждённому светлому концепту для iPhone и ноутбука. Все учебные данные остаются в браузере. При первом запуске этой версии активируется светлая тема (после этого темы можно менять в профиле). На главной сохранены настройка порядка виджетов, живой таймер, расписание и задания.
Публикация: загрузите содержимое архива в корень GitHub Pages. Перед обновлением экспортируйте резервную копию.
