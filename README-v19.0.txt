Моя Бауманка 19.0 — Foundation Update

Изменения:
- Задания: активные/архив (статусы Готово, Сдано, Принято), фильтр по предметам, сортировка по сроку или предмету, возврат из архива.
- Учёба: вкладка «Заметки», локальное сохранение и удаление заметок.
- Учёба: вкладка «Фокус», таймер 15/25/40/50 минут и история завершённых сессий.
- Общие CSS-переменные, новый кеш PWA и версионирование ресурсов.
- Аналитика успеваемости НЕ добавлена.

Публикация: распаковать и загрузить ВСЕ файлы в корень репозитория. Фото Братвы также лежат в корне. Публикуйте их только с согласия изображённых людей.
Перед обновлением скачайте резервную копию данных в профиле.
Не удаляйте PWA и не очищайте данные Safari.
Таймер не продолжает отсчёт после закрытия приложения; текущая незавершённая сессия не сохраняется.
Облачной синхронизации нет. Тестирование на реальном iPhone ещё необходимо.
